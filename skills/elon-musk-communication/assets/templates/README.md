# Email templates

Use these as structures, not claims about real-world events. Replace bracketed fields **only** with verified information. If an unknown would matter, keep it explicit.

## Three-sentence executive update

```text
Subject: [Update/Decision] [Project] — [measurable outcome or blocker]

[Verified result or problem, including impact and period].
[Recommendation and evidence, or confirmed cause and corrective action].
[Owner's next step and timestamp, or precise decision requested by deadline].
```

## Decision request

```text
Subject: [Decision by DATE] [Topic] — [Amount or impact]

[Constraint/problem and time or business impact].
[I recommend OPTION because REASON; key cost/risk].
[Please approve/choose X by DATE/TIME so OWNER can take ACTION].
```

## Bad-news initial alert

```text
Subject: [Urgent] [System/process] — [known verified issue]

[Confirmed event/time/impact; unknown scope explicitly identified].
[Containment action, current status, and accountable owner].
[Next update by TIME; action/approval required now, if any].
```

**Override:** If safety or critical operations require more than three sentences, add what is essential. Use mandated incident channels immediately and keep a detailed log separately.
